# Ls-Mill-Website

Official premium editorial web platform for **LS Mills Limited** (Theni, Tamil Nadu, India) — a world-class integrated textile manufacturer specializing in Ring Spinning (150,000 Spindles), Tsudakoma Airjet Weaving (200–1,500 TC), and Forward-Integrated Home Bed Linens (6,000 Sheets/Shift).

## 🌟 Overview & Design System
* **Brand Identity**: "Theni Nature & Textile" — Rooted in Nature, Refined Through Textile Craft.
* **Palette**: Forest Green (`#183D32`), Harvest Gold (`#D6A85F`), Cotton Ivory (`#F3F0E5`), Leaf Sage (`#789078`), Terracotta (`#B96F4A`), and Charcoal (`#242923`).
* **Typography**: Cormorant Garamond (Editorial Serif headlines), Plus Jakarta Sans (Modern Sans body), Cinzel (Classical markers).
* **Official Emblem**: Integrated vector SVG mark with the official monogram crest (`Ls_Mill_logo.svg`).

## 🛠️ Tech Stack
* **Framework**: Angular 19 (Standalone Components, Signals, Typed Reactive Forms)
* **Styling**: SCSS with CSS Variables & Asymmetric 12-Column Editorial Grid
* **Icons**: Custom lightweight SVG Lucide Icon library
* **Animations**: Native CSS Transitions & Intersection Observer Scroll Reveals
* **SEO & Meta**: Semantic HTML5, `robots.txt`, XML `sitemap.xml`, and strict accessibility (`prefers-reduced-motion` compliance)

## 🚀 Getting Started

### Prerequisites
* Node.js (v18 or higher)
* npm or yarn

### Installation
```bash
git clone https://github.com/suryakumars2022-ai/Ls-Mill-Website.git
cd Ls-Mill-Website
npm install
```

### Development Server
Run the local dev server:
```bash
npm start
# or
ng serve --port 4250
```
Navigate to `http://localhost:4250/`. The app will automatically reload if you change any source files.

### Production Build
Build for production:
```bash
npm run build
```
Output bundles are generated in `dist/ls-mills`.
